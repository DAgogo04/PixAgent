Under the Hood

How Pix Agent Works

A state-machine-driven agent: deterministic flow controls the stages, while the model provides semantic intelligence inside each stage.

Vision-Language Model

Perceiver

A VLM interprets the image and the user's goal, then routes the request to a supported skill. Low confidence triggers clarification instead of a guess.

Skill-based Input

Skill menu & presets

To lower the "I don't know how to describe it" barrier, the agent offers skill menus, process instructions (e.g. an ID-photo workflow), and preset prompts for common abstract words.

Tool Orchestration

Executor

Product sliders/options map to editing-node parameters. A preview–confirm separation and a single-task-per-conversation state keep edits safe and resumable.

Multi-metric Scoring

Evaluator & memory

A two-layer preference model with confidence thresholds decides auto-apply vs ask. Bad cases are classified by stage and flow back into the knowledge base and eval set.

Harness

One Harness Around the Model

The LLM is a stateless, probabilistic brain. The harness is everything built around it — the runtime loop, tools, context, memory, knowledge, guardrails and observability — that turns it into a reliable agent. Inside it, the runtime is a Graph (state machine).

How the agent stays safe

Every point-deducting or high-risk action is gated by an explicit checkbox and a preview step; pre- and post-generation content moderation, AI watermarking and over-edit/identity checks are built in. The agent is allowed to say "I can't" — it never hard-fills an answer it can't ground.
